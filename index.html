● 前置依赖模组

📦 EMF - Entity Model Features

实体模型特性，负责修改玩家骨骼、手臂模型与动画逻辑。

官方源 国内加速镜像

📦 ETF - Entity Texture Features

实体纹理特性，负责实体材质渲染与动画驱动。

官方源 国内加速镜像
