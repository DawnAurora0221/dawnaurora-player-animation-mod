DawnAurora Player Animation
Resource Pack

为 Minecraft 1.20.1 Fabric 重制更流畅的玩家动作表现。第一人称手部姿态、武器挥砍、物品切换与移动动画优化，让玩家动作更有重量感与自然节奏。

重要说明：这是资源包，不是模组。必须同时安装 EMF 和 ETF 两个前置模组才能正常使用。

Entity Texture Features (ETF)

实体纹理特性，资源包必需前置

自建加速镜像（推荐） CurseForge Modrinth

Entity Model Features (EMF)

实体模型特性，资源包必需前置

功能介绍

  • 重制玩家行走、奔跑、跳跃、坠落、游泳、攀爬动画
  • 第一人称手部动画与身体动作同步
  • 头部跟随镜头旋转，身体倾斜效果
  • 鞘翅滑翔、水下游泳专属动画
  • 完整睡眠动画：躺下、侧卧、翻身、调整姿势、深睡、起床、伸懒腰
  • 骑行动画：骑马、骑猪、乘船姿态
  • 武器动画：弓蓄力射箭、弩上弦发射、三叉戟投掷、重锤待机挥击；剑斧动作区分；空手格挡独立动画
  • 火把/灵魂火把/灯笼/灵魂灯笼统一持握动画
  • 新增：栅栏行走动画、方块边缘站立倾斜动画

常见问题 FAQ

  • Q：下载的资源包无法打开？A：确认文件完整，不要直接浏览器打开zip，放入resourcepacks文件夹。
  • Q：动画不生效？A：确认EMF、ETF版本正确，资源包在游戏内已启用。
