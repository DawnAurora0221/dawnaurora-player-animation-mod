前置依赖模组

必须全部安装，Dapa资源包才可以正常运行

📦 EMF ‑ Entity Model Features

实体模型扩展模组，负责骨骼、自定义实体模型、动画驱动，Dapa动画核心基础。支持Fabric/Forge/NeoForge，客户端模组。

前往Modrinth下载EMF

📦 ETF ‑ Entity Texture Features

实体纹理扩展模组，配合EMF实现实体材质、发光纹理、随机材质，联动渲染玩家动画，客户端模组。

前往Modrinth下载ETF

📋 模组加载顺序

游戏模组列表：先加载 ETF，再加载 EMF；
资源包排序：EMF资源包 → ETF资源包 → Dapa。顺序错误动画直接失效。

⚠️ 重要提示

EMF、ETF是Mod模组（jar），不是资源包zip！需要放入mods文件夹，不要丢进resourcepacks。

核心功能

全部自定义玩家动作动画，基于EMF+ETF实现

🍖 进食动画

吃东西时手臂抬起，平滑过渡，不再僵硬。

🛡️ 举盾格挡

手持盾牌拥有专属格挡姿态，手臂位置动态调整。

⚔️ 武器攻击

挥剑、工具攻击的手臂动作重写，手感更自然。

🔄 物品切换

切换武器、道具时加入过渡动画。

👀 第一人称适配

第一人称手部全部动作同步生效。

🧍 第三人称适配

第三人称全身骨骼动画同步渲染。
