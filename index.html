DawnAurora Player Animation Dapa

DawnAurora Player Animation（简称Dapa）是Minecraft 1.20.1 Fabric动画资源包，完全重写原版玩家动画，带来更流畅、拟人化的玩家动作。

⚠️ Alpha早期预览版：存在未完成动画、模型穿模等问题，不建议长期存档使用。
首选镜像下载 备选镜像下载 GitHub发布页兜底

版本信息

  • 发布类型：Alpha Early Preview
  • 支持游戏版本：Minecraft 1.20.1
  • 加载器：Fabric Loader
  • 强制前置依赖：Entity Texture Features (ETF), Entity Model Features (EMF)

已实现功能

  • 第三人称完整玩家动画：行走、奔跑、跳跃、坠落、游泳
  • 第一人称手部动画，与身体动作同步
  • 身体倾斜、头部跟随镜头旋转
  • 攀爬、鞘翅滑翔、水下游泳专属动画

安装教程

  1. 安装 Minecraft 1.20.1 Fabric Loader
  2. 安装前置依赖 ETF 与 EMF 模组，放入mods文件夹
  3. 将Dapa资源包zip放入resourcepacks文件夹
  4. 在游戏资源包菜单启用 DawnAurora Player Animation

已知问题

  • 部分动画存在模型穿模、抖动
  • 物品交互动画尚未完全实现
  • 与其他修改玩家模型/动画的资源包冲突
